Sign in to manage your websites

This dashboard uses your GitHub account to save your site list and add Google Analytics to your sites. Sign in with a GitHub access token. You create it once.

  1. Open GitHub → New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick pinservs plus every repo that holds a site you manage.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it below.

Your token stays in this browser and is only sent to GitHub. Only someone with write access to the pinservs repo can change anything here.
