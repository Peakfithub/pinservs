Store app

Turnkey Store app files

These files run the live store: Stripe checkout, member accounts, private PDF and ZIP downloads, and the admin dashboard. They deploy to Cloudflare Workers (free plan) with the Deploy Turnkey Store action in the pinservs GitHub repo.

Download the app (.zip)

  • Setup takes about 15 minutes. The steps are in README.md: a Cloudflare account, a Stripe key, five GitHub secrets, then Run workflow.
  • Keys and passwords live only in GitHub and Cloudflare secrets, never in these files.
